## 2024-05-26 - Predictable Temporary Filenames Vulnerability
**Vulnerability:** The application used `hashlib.sha256(file.getvalue()).hexdigest()` to generate temporary filenames when uploading PDFs.
**Learning:** Generating custom temporary filenames based on hashes or predictable content creates a risk of file collisions or denial of service if an attacker predicts or manipulates the filename. This pattern should be avoided in Python. Furthermore, to prevent disk leaks and ensure robustness, filename assignment (`filename = temp_file.name`) should occur before write operations (`temp_file.write(...)`), so that the `finally` block can properly clean up the temporary file even if an exception occurs during the write process (e.g. disk full).
**Prevention:** Always use secure, built-in library functions for temporary file handling, such as `tempfile.NamedTemporaryFile`, which handles secure, random filename generation and proper permissions. Ensure cleanup occurs safely in a `finally` block using `delete=False` when the file needs to be closed and passed to another process/loader (like PyPDFLoader).
